# Peluquería · Demo de reservas

Demo web de reserva de citas para una peluquería, con un formulario de reserva y un panel de administración. HTML y JavaScript en el cliente, sin servidor.

## Cómo verla

Abre `index.html` (o `index2.html`) en el navegador.

## Aviso de seguridad

Es **solo una demostración**. El acceso al panel de administración se comprueba en el navegador con una contraseña escrita en el propio código, así que no ofrece seguridad real. No debe usarse con datos reales. Una versión de producción necesitaría un servidor con autenticación.
